# Roadmap

The current foundation contains a starter screen, a Gradle Wrapper build, JVM tests, and CI-generated debug APKs.

| Milestone | Planned work |
| --- | --- |
| Developer Preview | Navigation, accessible Compose screens, and the core data model |
| Alpha | Manual probes against verified targets, configurations, and a signed installable APK |
| Beta | Explicit background sessions, local monitoring history, and device sleep testing |
| Release candidate | Device coverage, battery and traffic measurements, and upgrade testing |
| Stable | Signed distribution after regression testing |

Scope and release timing depend on verification and maintainer review. APK distribution is the initial target. A future F-Droid submission would be evaluated separately.
