# Roadmap

The current foundation contains the Material 3 design system, the four-tab navigation shell, the overview, the domain-backed checks list and details, the universal check editor for all P0 protocols, localized settings with a first-run flow, internal TCP Connect, TLS, system/direct DNS, HTTP/HTTPS and ICMP Echo probe runners tested against local resources, a Gradle Wrapper build, JVM tests, and CI-generated debug APKs.

| Milestone | Planned work |
| --- | --- |
| [Technical Preview v0.1.0-dev.1](https://github.com/chuck852/LinkSonda/issues?q=is%3Aissue+milestone%3Av0.1.0-dev.1) | Published starter-screen APK for development testing, with a debug signature and no network functionality. |
| [Developer Preview v0.2.0](https://github.com/chuck852/LinkSonda/issues?q=is%3Aissue+milestone%3Av0.2.0) | Published debug-signed UI preview with the Material 3 design system, four-tab navigation, domain-backed checks and details, universal check editor, localized settings and first-run flow. No network functionality. |
| [Alpha](https://github.com/chuck852/LinkSonda/issues?q=is%3Aissue+milestone%3Av0.3.0) | Manual probes against verified targets, configurations, and a signed installable APK |
| [Beta](https://github.com/chuck852/LinkSonda/issues?q=is%3Aissue+milestone%3Av0.4.0) | Explicit background sessions, local monitoring history, and device sleep testing |
| [Release candidate](https://github.com/chuck852/LinkSonda/issues?q=is%3Aissue+milestone%3Av1.0.0) | Device coverage, battery and traffic measurements, and upgrade testing |
| [Stable](https://github.com/chuck852/LinkSonda/issues?q=is%3Aissue+milestone%3Av1.0.0) | Signed distribution after regression testing |
| [v1.1.0](https://github.com/chuck852/LinkSonda/issues?q=is%3Aissue+milestone%3Av1.1.0) | Advanced protocols, graphs, presets and diagnostics |
| [v1.2.0](https://github.com/chuck852/LinkSonda/issues?q=is%3Aissue+milestone%3Av1.2.0) | Android widgets, Quick Settings and protocol research |

Scope and release timing depend on verification and maintainer review. Approved APKs are distributed through [GitHub Releases](https://github.com/chuck852/LinkSonda/releases). F-Droid is deferred. Public probes follow the [probe policy](docs/PROBE_POLICY.md).
