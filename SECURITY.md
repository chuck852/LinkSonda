# Security Policy

Report suspected vulnerabilities privately through **Security → Report a vulnerability** when that option is available. If it is unavailable, use a contact method listed on the [maintainer's GitHub profile](https://github.com/chuck852), or ask for a private channel without sharing the vulnerability in public.

Include the affected commit or build, Android version, impact, and the minimum information needed to reproduce the issue. Remove credentials, private network details, and unrelated personal data. Give the maintainer time to investigate before publishing details.

The project is at the foundation stage. Reports should identify the exact tested commit or APK. Development APKs are signed with a debug key.
