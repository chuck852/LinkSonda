# LinkSonda brand assets

The supplied design uses a globe and a monitoring pulse. Each PNG in this directory has a matching SVG source. Use `logo.png` for README, the mark variants where a transparent or monochrome mark is needed, and `social-preview.png` (1280 × 640) for **Settings → General → Social preview** on GitHub.

Android loads the launcher foreground and background from the adaptive icon resources. Compatible launchers can use the monochrome layer on API 33 and later. The density-specific square and round PNGs provide legacy artwork. Future notifications should use `R.drawable.ic_stat_linksonda` as the small icon.
