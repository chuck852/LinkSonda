## LinkSonda Developer Preview v0.1.0-dev.1

This technical preview demonstrates installation and launch of the LinkSonda starter screen on Android 8.0 or later (API 26+). This build has no network diagnostics, network permission, background monitoring, notifications, or incident history.

The APK is debuggable and signed with a CI debug key. Android requires the same signing key for in-place updates. Use a disposable emulator or a clean test installation, especially if you already have a different LinkSonda build.

Download `LinkSonda-debug.apk` and `SHA256SUMS` to the same directory. Check the digest with `sha256sum -c SHA256SUMS`, then install with `adb install LinkSonda-debug.apk`. `LinkSonda-license-notices.tar.gz` contains the Apache-2.0 license, project notices and third-party notices. The APK reports Android version name `0.1.0`. The GitHub tag identifies this preview.
