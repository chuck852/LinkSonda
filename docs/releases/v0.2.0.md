## LinkSonda UI Developer Preview v0.2.0

This preview demonstrates the current LinkSonda interface on Android 8.0 or later (API 26+). It includes the Material 3 design system, four-tab navigation, an empty production overview, a domain-backed checks list and details, a universal check editor for all P0 protocols, and localized settings with a first-run flow. Settings and the selected first-run profile persist locally, in English or Russian, with system, light and dark themes.

This build does not perform network diagnostics. It has no `INTERNET` permission, no probe engine, no background monitoring, no real history storage and no incident notifications. Checks, results, presets and history in the production interface are empty or explicitly unknown until a real engine is connected. Demo scenarios exist only in debug tooling and tests; they are not measurements and are not shown as results in the release APK.

The only declared permission is `POST_NOTIFICATIONS`. Android requests it only when notifications are enabled in Settings; denying it leaves manual checks and the editor usable. The app has no account, cloud backend, location access or analytics.

The APK is debuggable and signed with a CI debug key. Android requires the same signing key for in-place updates. Use a disposable emulator or a clean test installation, especially if you already have a different LinkSonda build.

Download `LinkSonda-debug.apk` and `SHA256SUMS` to the same directory. Check the digest with `sha256sum -c SHA256SUMS`, then install with `adb install LinkSonda-debug.apk`. `LinkSonda-license-notices.tar.gz` contains the Apache-2.0 license, project notices and third-party notices. The APK reports Android version name `0.2.0` (version code 2). The GitHub tag identifies this preview.

Known limitations: a full TalkBack pass remains open in #31; DataStore migration remains open in #13; permanent release signing remains open in #7. Network probes, background monitoring, presets and local history are planned.

The build uses Gradle 9.6.1, Android Gradle Plugin 9.3.1, Kotlin and Compose Compiler 2.4.21, and JDK 25.
